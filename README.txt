FAITH ACADEMY EKET WEBSITE CONCEPT
==================================

This is a responsive website concept inspired by the clean, confident layout patterns of Access Bank's corporate website. It does not copy Access Bank's branding or exact design.

SCHOOL PHOTOGRAPHS
------------------
All 36 image files retrieved from the connected Outlook mailbox are included in assets/images/ and are represented in the gallery. The gallery filters and lightbox work locally. The crest and admissions poster supplied in the image set are also used in relevant sections.

To preview: extract the project ZIP and open index.html in a modern browser. For best results, serve the folder using any simple local web server. Google Fonts are loaded online; system fonts are used if offline.

IMPORTANT BEFORE PUBLISHING
---------------------------
- Verify all official contact details, including the publicly listed phone number and location.
- Confirm exact official mission and vision wording with the school before publishing it as a quotation.
- Confirm permission to publish the photographs and the school crest.
- The enquiry form is a front-end demo. It opens a mailto draft and is not connected to a school server. Configure a verified recipient or backend before launch.
- No fees, admission deadlines, examination results, staff biographies, or unverified facilities have been invented.
- The photos are used from the Outlook image collection; the original filenames are retained for easy replacement and auditing.
